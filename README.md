# simgrammar-media

Release assets for the videos on [simgrammar.com](https://simgrammar.com): the episodes and shorts of *The Grammar of Simulation*. Each release holds the files `media/published.yaml` in [yoheinakajima/simgrammar](https://github.com/yoheinakajima/simgrammar) lists, with their sha256 values, and the site's Pages workflow fetches them from here.

The videos live in this repository, not the main one, because Zenodo archives every release of the main repository as a version of the paper. Do not switch Zenodo on for this repository.
